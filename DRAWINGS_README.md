# AQUILA Sovereign — Engineering Drawing Pack

## Overview

Production-ready engineering drawings for all 65 BOM components + 14 exploded assembly sheets,
following **ASME Y14.5** / **ISO 128** standards (third-angle projection).

Generated by `generate_drawings.py` using the standards from
"Engineering Working Drawings Basics" (MENG 204, Dr. Ala Hijazi).

## Sheet Standards

Each component sheet includes:
- **ISO A2 sheet** (594×420mm) with drawing frame and margins
- **Title block** (bottom-right): company, title, drawing number, revision, scale, units, material, tolerance, projection symbol, sheet number
- **Revision block** (above title block): Rev A, initial release
- **Notes block** (bottom-left): 5 standard notes
- **Orthographic views** (third-angle projection):
  - Front view (top-left)
  - Top view (below front)
  - Right view (right of front)
- **Isometric view** (top-right, 30°/30° axonometric)
- **Dimension lines** with extension lines and arrowheads:
  - Width (horizontal, below front view)
  - Height (vertical, left of front view)
  - Depth (horizontal, below right view)
- **Centerlines** for cylindrical parts (dashed red)

Each assembly sheet includes:
- **ISO A1 sheet** (841×594mm)
- **Exploded isometric view** with all components separated vertically
- **Explode lines** (dashed orange) connecting components in assembly order
- **Balloon callouts** (numbered circles) for each component
- **BOM table** (right side): Item, Part No, Description, Qty, Material
- **Title block** with assembly drawing number

## Drawing Number System

Per the Engineering Working Drawings Basics (page 21-22), drawings use hierarchical numbering:
- **Component drawings:** `ASD-AA.BB` (AA = subsystem index, BB = part within subsystem)
- **Assembly drawings:** `ASD-ASSY-TYP-NN` (TYP = SUB/ZONE/PHA, NN = sequence)

## Grouping Schemes

### By Subsystem
Components grouped by their BOM subsystem assignment (e.g., Compute Core, EO/IR Camera, Subsurface Radar).

### By Drone Zone
Components mapped to physical zones on the drone:
- **Zone A — Nose:** EO/IR, gimbal, photogrammetry, stereo vision
- **Zone B — Bay 1 (Forward):** Compute core, carrier board, payload pod
- **Zone C — Bay 2 (Mid):** Radar, QCL, photoacoustic, spectrometer, acoustic, seismic
- **Zone D — Bay 3 (Aft):** DNA sequencer, soil sampler, pneumatic, env sensors
- **Zone E — Tail:** Batteries, power conversion, control, comms, swarm
- **Zone F — Wings:** Drone platform, actuation, mechanical interface

### By Mission Phase
- **Phase 1 — Alta X:** Basic flight + EO/IR (electric platform)
- **Phase 2 — Firefly:** Full sensor stack (gas-hybrid heavy lift)
- **Phase 3 — Bio-Intel:** DNA sequencing + sampling + bio sensors

## How to Regenerate

```bash
# Install dependencies
pip install ezdxf matplotlib openpyxl

# Generate all drawings (65 components + 14 assemblies)
python generate_drawings.py

# Generate single component
python generate_drawings.py --component UAV-001

# Generate assemblies only
python generate_drawings.py --assembly all
python generate_drawings.py --assembly subsystem
python generate_drawings.py --assembly zone
python generate_drawings.py --assembly phase
```

Output directory structure:
```
drawings/
├── dxf/    # AutoCAD R2018 compatible
├── pdf/    # Printable (multi-page capable)
├── svg/    # Web-embeddable vector
└── png/    # 300 DPI raster
```

## Standards Reference

- **Sheet layout:** ISO A-series (A0-A4) with frame, margins, zoning
- **Title block:** Bottom-right, per page 2-3 of reference
- **Projection:** Third-angle (US standard), per page 6-7
- **Dimensioning:** Chain + baseline methods, per page 9-11
- **Section views:** Full/half/broken-out, per page 14-17
- **Assembly drawings:** BOM + balloons + exploded views, per page 19-20
- **Numbering:** Hierarchical XXX.AA.BB, per page 21-22
